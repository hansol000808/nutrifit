# NutriFit | 맞춤형 식단 매니저

신체 정보와 식단 목표를 바탕으로 하루 목표 칼로리와 탄수화물, 단백질, 지방 섭취량을 계산하고, 식사 기록과 목표 달성도를 확인하는 웹 앱입니다.

## 주요 기능

- 성별, 나이, 키, 체중, 활동량과 다이어트, 유지, 벌크업 목표에 따른 하루 목표 계산
- 날짜별 식사 기록과 칼로리 및 영양소 합계 확인
- 목표 대비 섭취량과 달성도 시각화
- 기본 음식 검색, 사용자 음식 등록과 수정, 즐겨찾기
- 자주 먹는 음식들을 식단 조합으로 저장하고 한 번에 기록
- 날짜별 목표 보존과 지난 날짜의 식사 기록 조회
- 로컬 프로필 생성, 선택과 삭제 및 프로필별 기록 관리
- 샘플 데이터 체험과 빈 기록으로 시작하기

## 사용 방법

1. 로컬 프로필을 만들고 샘플로 체험하거나 빈 기록으로 시작합니다. 기존 프로필을 선택해 이어서 사용할 수도 있습니다.
2. 신체 정보와 활동량, 식단 목표를 설정하고 하루 목표를 확인합니다.
3. 음식과 섭취량을 선택해 식사 기록을 추가합니다.
4. 하루 섭취 합계와 목표 달성도를 확인합니다.
5. 즐겨찾기와 식단 조합으로 자주 먹는 음식을 관리합니다.
6. 날짜를 이동해 이전 기록을 조회합니다. 지난 날짜의 식사 기록은 읽기 전용입니다.

## 데이터 저장

입력한 내용은 현재 브라우저의 `localStorage`에 저장됩니다. 계정 가입이나 로그인, 서버 데이터베이스 연결은 필요하지 않습니다.

- 신체 정보, 음식, 즐겨찾기, 식단 조합, 식사 기록과 목표 이력을 프로필별로 저장합니다. 샘플 데이터나 빈 기록으로 초기화하는 작업은 선택한 프로필에만 적용됩니다.
- 프로필 선택은 탭별로 유지됩니다. 같은 브라우저의 다른 탭에서 서로 다른 프로필을 사용할 수 있습니다.
- 새로고침한 뒤에도 같은 브라우저에 저장된 기록을 불러옵니다.
- 이전 버전의 단일 저장 데이터는 기존 프로필로 복사하며 원본 저장 항목은 보관합니다.
- 로컬 프로필은 기록을 구분하는 기능입니다. 같은 브라우저에서 사용할 수 있는 프로필 사이에 로그인이나 접근 제한은 없습니다.
- 브라우저나 기기 간 동기화, 서버 백업과 계정 복구는 제공하지 않습니다.
- 브라우저 저장소를 지우거나 비공개 브라우징을 종료하면 기록을 사용할 수 없게 될 수 있습니다.
- 같은 프로필을 여러 탭에서 동시에 변경하면 마지막 저장이 앞선 변경을 덮어쓸 수 있습니다. 동시 변경을 병합하는 기능은 없습니다.

## 로컬 실행

Node.js 20 이상과 Git이 설치된 환경에서 실행합니다. 외부 패키지 설치나 별도 빌드는 필요하지 않습니다.

```sh
git clone https://github.com/hansol000808/nutrifit.git
cd nutrifit
npm start
```

브라우저에서 [http://127.0.0.1:4173/nutrifit/](http://127.0.0.1:4173/nutrifit/)을 엽니다. 서버를 종료하려면 터미널에서 `Ctrl+C`를 누릅니다. 로컬 서버는 정적 파일 미리보기용이며 앱 데이터는 브라우저에 저장됩니다.

## 테스트

```sh
npm test
```

Node.js 기본 테스트 러너로 `tests/*.test.cjs`를 실행합니다. 입력과 날짜 검증, 목표 계산과 저장 거부, 목표별 전략 교체, 음식과 식사 기록, 과거 기록 및 목표 보존, 프로필별 저장과 이전 데이터 이관을 검사합니다.

변경 이력과 날짜별 검증 범위는 [프로젝트 문서](docs/PROJECT.md)에서 확인할 수 있습니다.

## 프로그램 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 진입점과 스크립트 연결 |
| `style.css` | 화면 스타일과 반응형 배치 |
| `app.js` | 화면 렌더링, 사용자 입력과 브라우저 저장 |
| `lib/core.js` | 입력 검증, 계산 위임, 음식과 식사 기록 관리 |
| `lib/target-strategies.js` | 목표별 계산 전략과 공통 계산기 |
| `lib/profiles.js` | 로컬 프로필 생성·삭제, 프로필별 저장과 이전 데이터 이관 |
| `tests/core.test.cjs` | 핵심 로직 테스트 |
| `tests/profiles.test.cjs` | 프로필 분리와 저장 상태 테스트 |
| `scripts/serve.cjs` | 로컬 정적 파일 서버 |
| `assets/icon.svg` | 앱 아이콘 |
| `docs/desktop.jpg`, `docs/mobile.jpg` | 화면 예시 |

목표별 계산 정책은 `MaintainStrategy`, `DietStrategy`, `BulkUpStrategy`로 나뉩니다. `CalorieCalculator`는 전달받은 전략을 호출하고 기초대사량 계산, 칼로리 한도 보정과 최종 영양소 계산을 공통으로 처리합니다. `core.calcTargets`는 프로필을 검증한 뒤 목표에 맞는 전략을 선택해 계산을 위임합니다.

HTML, CSS와 JavaScript를 그대로 제공하는 정적 웹 앱입니다. 자산은 상대 경로로 연결되며 GitHub Pages의 `/nutrifit/` 경로에서 동작합니다.

## 기능 범위

- 음식 영양 정보는 기본 목록과 사용자 입력을 사용합니다.
- 칼로리와 영양소 목표는 입력값과 계산식에 따른 추정치입니다.
- 계산된 단백질과 지방의 열량 합계가 하루 목표 칼로리를 초과하면 새 목표를 저장하지 않습니다. 이전에 저장한 목표와 식사 기록은 유지하며, 저장된 목표에 열량 불일치가 있으면 안내를 표시합니다.
- 외부 식품 데이터 API, 자동 식단 추천, 사진 인식, 주간 및 월간 분석은 제공하지 않습니다.
